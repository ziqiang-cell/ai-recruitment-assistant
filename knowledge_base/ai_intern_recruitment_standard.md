# AI 应用开发实习生招聘标准

以下内容仅用于 AI 招聘助手 RAG 功能测试。

岗位方向：AI 应用开发实习生，参与基于大模型的业务应用开发与调试。

- Python：具备语法基础，能够阅读代码、编写函数，并完成一个可运行的项目。
- LLM API：有调用 DeepSeek、OpenAI 等大模型 API 的实践，了解 API Key 和基本错误处理。
- Prompt Engineering：能编写清晰的 Prompt，约束模型只依据给定资料回答，并设计 JSON 结构化输出。
- RAG：了解文档解析、文本切分（Chunk）、Embedding、向量检索和利用检索资料生成答案的流程。
- Git：了解 branch、commit、merge、push 等基本操作，能解释自己参与的代码修改。
- Web：Streamlit 或 FastAPI 的实际经验属于加分项，不是所有岗位的硬性要求。
- Debug：能利用 Traceback、日志和简单测试定位问题，说明排查步骤。

评价时应以具体岗位 JD 为准。知识库列出的技能只是参考标准，未在简历中体现的经历需要进一步确认。
