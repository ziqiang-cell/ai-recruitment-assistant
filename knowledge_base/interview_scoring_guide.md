# 面试能力参考标准

以下内容仅用于 AI 招聘助手 RAG 功能测试。

AI 应用开发实习生面试时，可参考以下能力权重：

- Python 基础与项目实践：30
- LLM API 调用与错误处理：20
- Prompt Engineering 与 JSON 结构化输出：15
- RAG 原理和简单实现：20
- Git 与 Debug：10
- Web 或 API 应用开发：5

总分：100。

这些数字仅供面试官理解评价重点。当前项目不由 Python 按权重直接计算匹配分数；仍由大模型结合具体 JD、简历证据和参考标准综合估算。简历未提及的能力应提出针对性面试问题，不应直接判定为能力差。
